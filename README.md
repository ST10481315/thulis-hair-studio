## Project Overview

Thuli's Hair Studio is a small hair salon that provides stylish and
affordable hairstyling services. The purpose of this website is to give
the salon an online presence and make it easier for customers to find
information about the business and enquire about hairstyles.

The website will provide information about the salon, available
services, prices and contact details. Customers will also be able to
submit an enquiry and request a quote.

---

## Website Goals and Objectives

The main goals of the website are:

- To create an online presence for Thuli's Hair Studio.
- To provide customers with information about the salon.
- To display available hairstyles and prices.
- To make it easier for customers to request a quote.
- To make the website easy to navigate.
- To improve communication between the salon and its customers.

---

## Key Features and Functionality

The website will include:

- Contact page

---

## Website Pages

### Home

The Home page introduces Thuli's Hair Studio and provides a brief
overview of the services offered.

### About Us

The About Us page provides information about the history, mission,
vision and target customers of the salon.

### Services

The Services page displays the hairstyles offered by the salon and
their prices.

### Enquiry

The Enquiry page allows customers to provide their details, select
a hairstyle and request a quote or appointment.

### Contact

The Contact page provides the salon's contact details and location
information.
