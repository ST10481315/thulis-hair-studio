## Project Overview

Thuli's Hair Studio is a small hair salon that provides stylish, neat and affordable hairstyles. The website was created to give the salon a professional online presence and make it easier for customers to find information about the salon.

The website allows customers to view the services offered, learn about the salon, make enquiries and find contact information and locations.

---

## Website Goals and Objectives

The main goals of the website are to:

- Give Thuli's Hair Studio a professional online presence.
- Display the hairstyles and services offered.
- Make it easier for customers to contact the salon.
- Allow customers to send enquiries and request quotes.
- Provide information about the salon and its locations.
- Make the website easy to navigate.

---

## Target Audience

The website is aimed at:

- Students
- Young adults
- Working professionals
- Customers looking for affordable hairstyles
- People interested in braiding and hairstyling services

---

## Key Features and Functionality

The website contains five main pages:

### Home Page
Introduces visitors to Thuli's Hair Studio and provides a call to action.

### About Us
Provides information about the history, mission, vision and target customers of the salon.

### Services
Displays the different hairstyles and prices offered by the salon.

### Enquiry
Contains a form that allows customers to request a quote or make an enquiry.

### Contact
Provides contact details, operating hours and information about the salon locations.
